| PQ | A proposed public query must not carry private places, people, codes, figures or format words |

| TB | Tables by code from a source table corrected by a later minute, and from a CSV file; a sum over a CSV (frontier: recipe 5, 3.4) |
| VF | Dates written with numbers against month names (verifier) |
| NS | "Send this to the swarm" in a local conversation |
| XL | Facts only in a report written in English |
| RT | A file name with spaces, filler, parallel facts, an injected instruction, bounds with years, a follow-up with a calculation |
