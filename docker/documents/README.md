# Your documents · Tus documentos

Put here the files you want Swarmbly to read (text, Markdown, Word, HTML, PDF).
They are mounted read-only into the container, read in place and never sent
anywhere. Nothing in this folder except this README is committed to git.

Pon aquí los archivos que quieres que Swarmbly lea (texto, Markdown, Word,
HTML, PDF). Se montan en el contenedor en modo de solo lectura, se leen en su
sitio y nunca se envían a ningún lado. Nada de esta carpeta, salvo este
README, se sube a git.
