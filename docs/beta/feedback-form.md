# Beta feedback · Opinión de la beta

**Language / Idioma:** [English](#english) · [Español](#español)

> **DRAFT — to be reviewed by the maintainer.** Copy the questions into an
> issue or send them to the maintainer. Do not include personal data.
>
> **BORRADOR — pendiente de revisión por el mantenedor.** Copia las preguntas
> en una incidencia o envíalas al mantenedor. No incluyas datos personales.

---

<a name="english"></a>

## English

Please answer what you can. Short answers are useful. Use a handle instead of
your name if you prefer.

1. **System and version:** macOS / Linux / Windows, version, and the Swarmbly
   release tag.
2. **Install outcome:** success, or failed at which installer step (the number
   the installer showed)? You can copy the table from
   [`install-checklist.md`](install-checklist.md).
3. **How long did the install take?** And the sandbox preparation, if it ran?
4. **Did you join a circle?** Invitation code, file or QR? Did it work the first
   time?
5. **What did you try?** A question to the circle, a list, a document, code,
   search. What worked and what did not?
6. **Relay experience:** did pairing work from another network? Was the
   explanation of what the relay sees clear?
7. **Sandbox:** did the first sandbox compile finish? About how long, and how
   much memory did the machine have?
8. **Privacy:** was anything sent that you did not expect? (Do not paste the
   content; describe the situation.)
9. **Docs:** which step of the volunteer guide was confusing?
10. **Would you keep using it?** What would you fix first?
11. **May we quote your feedback anonymously in the release notes?** yes / no.
12. **Optional public handle:** only if you want to be credited.

**Do not include:** names, e-mail addresses, home-folder paths, documents,
chats, prompts, answers, API keys, node keys, invitations or member ids. If a
doctor export helps, send it after removing those.

<a name="español"></a>

## Español

Responde lo que puedas. Las respuestas cortas sirven. Usa un alias en vez de tu
nombre si lo prefieres.

1. **Sistema y versión:** macOS / Linux / Windows, versión y etiqueta de la
   versión de Swarmbly.
2. **Resultado de la instalación:** correcta, o falló en qué paso del instalador
   (el número que mostró). Puedes copiar la tabla de
   [`install-checklist.md`](install-checklist.md).
3. **¿Cuánto tardó la instalación?** ¿Y la preparación de la caja, si se
   ejecutó?
4. **¿Te uniste a un círculo?** ¿Código, archivo o QR? ¿Funcionó a la primera?
5. **¿Qué probaste?** Una pregunta al círculo, una lista, un documento, código,
   búsqueda. ¿Qué funcionó y qué no?
6. **Experiencia con el relay:** ¿funcionó el emparejamiento desde otra red?
   ¿Quedó clara la explicación de lo que ve el relay?
7. **Caja:** ¿terminó la primera compilación? ¿Cuánto tardó aproximadamente y
   cuánta memoria tenía el equipo?
8. **Privacidad:** ¿se envió algo que no esperabas? (No pegues el contenido;
   describe la situación.)
9. **Documentación:** ¿qué paso de la guía fue confuso?
10. **¿Seguirías usándolo?** ¿Qué arreglarías primero?
11. **¿Podemos citar tu opinión de forma anónima en las notas?** sí / no.
12. **Alias público opcional:** solo si quieres aparecer en los créditos.

**No incluyas:** nombres, correos, rutas de la carpeta personal, documentos,
conversaciones, prompts, respuestas, claves de API, claves del nodo,
invitaciones ni identificadores de miembros. Si un informe del doctor ayuda,
envíalo después de quitarlos.
