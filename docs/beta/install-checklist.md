### Counting the target

- Use only lists that volunteers chose to send.
- Success rate per OS = successes ÷ (successes + failures). The beta target is
  ≥ 90 % per OS, and overall.
- Do not count a failed attempt twice when the same volunteer retries; use the
  final outcome and note the retry in the issue.
- Never add names, e-mail addresses, home-folder paths or a machine serial
  number to the tally.

### Cómo se cuenta el objetivo

- Usa solo las listas que las personas voluntarias decidieron enviar.
- Tasa de éxito por sistema = éxitos ÷ (éxitos + fallos). El objetivo de la
  beta es ≥ 90 % por sistema y en total.
- No cuentes dos veces un intento fallido si la misma persona reintenta; usa el
  resultado final y anota el reintento en la incidencia.
- No añadas nombres, correos, rutas de la carpeta personal ni números de serie
  del equipo al recuento.
