Two rules that apply throughout, and both cost a run when broken:

1. **Do not change any file in `swarmbly_v0/` between a `-dev` tier and its


   Rehearsals write to **`results/rehearsal/`**, never to `results/`, so no
   glob and no `[-1]` can pick one up as the newest real run.

## Step 3 — `comp-final` (~2 h) — the declared verdict, once

```bash
bash scripts/run_ollama.sh comp-final results/comp-dev-<stamp>
```

Pass the **directory**, not a τ value. The tier reads the threshold, the frozen
corpus digest, the split and now the code fingerprint out of that run, and
refuses if any of the four disagrees.

The hypothesis, fixed before either run and recorded in
`docs/PREREGISTRATION_composition.md`:

> Composition at ρ = 4.0, N = 3, k = 1 costs **less than 5 points** of
> constraint satisfaction against its monolithic baseline — judged on the
> **upper bound** of a bootstrap clustered by prompt, with **N = 8 as a control
> required to fail**.

The tier prints the verdict itself. Three readings, and only one of them is
about fragmentation:

* **The control passed too** → the instrument is not separating the arms and
  **neither number is evidence**. This is worse news than the declared cell
  failing.
* **`n_prompts` under 20** → no verdict at all, whatever the point estimate
  says. Do not quote the interval.
* Otherwise → MET or NOT MET, on the upper bound.

Remember the asymmetry: where `baseline_at_ceiling` is high the paired
difference cannot go negative, so a **pass is a real bound on the cost** and a
**fail cannot be read as fragmentation helping**.

## The one open question, which no run answers

**Duplication versus ρ.** The repair covers the case where each question names
one part of the material and refuses the case where two questions need the same
part — because duplicating a unit inflates `sum(|task_i|)` above `|P|` and
raises the reachable ρ floor.

But the **oracle partition duplicates freely**. It hands each claim exactly the
facts it requires, and those sets overlap. So the partition that is viable *in
principle* is a **covering**, not a partition, and ρ charges for every
duplicated token.

Allowing duplication buys back `reduce`, `chain` and `compose` at the cost of a
ρ floor that rises with the overlap. Forbidding it means those classes are not
fragmentable by this implementation. That is an architecture decision, it is
yours, and it does not need to be made before these runs.
