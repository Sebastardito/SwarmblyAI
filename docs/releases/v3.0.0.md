## English

**Released 2026-10-25.** From this release, this repository is the umbrella of Swarmbly AI: one download and one installer for the three components, versions tested together, and documentation for the whole project.

### What is in this distribution

| Component | Version | Source here | Commit | DOI |
|---|---|---|---|---|
| SwarmblyCore | 0.1.0 (`swarmbly-v0`) | in-tree, [`SwarmblyCore/`](../../SwarmblyCore/) | this release | [10.5281/zenodo.21956743](https://doi.org/10.5281/zenodo.21956743) |
| SwarmblyLCE | 0.2.0.dev0 | mirror, [`SwarmblyLCE/`](../../SwarmblyLCE/) | `5fb70b9` | [10.5281/zenodo.23289041](https://doi.org/10.5281/zenodo.23289041) |
| SwarmblyApp | 0.3.0 | mirror, [`SwarmblyApp/`](../../SwarmblyApp/) | `e6af928` | [10.5281/zenodo.23322638](https://doi.org/10.5281/zenodo.23322638) |

SwarmblyLCE 0.2.0 and SwarmblyApp 0.3.0 are not yet released in their own repositories, so this first distribution pins their commits ([`components.lock`](../../components.lock)). Later distributions pin component tags.

### Highlights

- **One repository.** Everything that was here (protocol, specification, reference implementation, V0 harness, benchmark, documents) moved unchanged into `SwarmblyCore/`. SwarmblyLCE and SwarmblyApp are exact mirrors (`git subtree --squash`) checked in continuous integration.
- **Interactive installer** for macOS, Linux and Windows: *quick install* (everything recommended, explained once, no further questions) or *custom install* (step by step). It sets up an isolated Python environment, the three components, Ollama and chat models sized to your RAM plus an embedding model, PDF reading and local web search (SearXNG) as extras, a `swarmbly` command, desktop shortcuts, `swarmbly doctor` and uninstall. Tested in CI on the three systems.
- **What the app does today** (SwarmblyApp 0.3.0): privacy lanes that keep requests about you on your computer; a private memory over your own documents (LCE C1: hybrid retrieval over text, Word, HTML and PDF); public evidence by name only (Wikidata, Wikipedia, PubMed, optional local SearXNG); LAN swarms with authenticated peers, hedging and immediate local fallback; a monitor that shows how each answer was made.
- **Documentation for the whole project**, in English and Spanish: a redesigned README with an animated flow diagram, figures of the published measurements, a simulation of the coverage model and an app tour; architecture, installation, components and maintenance, roadmap.
- **Funding:** [buymeacoffee.com/swarmbly](https://buymeacoffee.com/swarmbly). Support never buys influence over the roadmap, licence or governance.

### Upgrading from 2.x

- The protocol code now lives in `SwarmblyCore/`. Paths such as `swarmbly_v0/`, `swarmbly_ref/`, `benchmark_v7/` or `docs/` are now `SwarmblyCore/swarmbly_v0/`, `SwarmblyCore/swarmbly_ref/`, `SwarmblyCore/benchmark_v7/`, `SwarmblyCore/docs/`.
- Installing the protocol package straight from git at a 3.x commit needs the subdirectory: `pip install "swarmbly-v0 @ git+https://github.com/Sebastardito/SwarmblyAI.git@v3.0.0#subdirectory=SwarmblyCore"`. Pins to 2.x commits keep working unchanged.
- The DOIs of v1 and v2 remain valid; this release is a new version of the same Zenodo concept.

### Known limitations

Alpha software. Internet-wide swarms are not implemented; distributed long-form writing does not beat a single local model; the coherence-tax criterion is not met on its held-out test and the confidence map remains withdrawn; the measurements of the local memory come from one person's material (development set) and a held-out benchmark is planned for 3.1. Details in the README section *What works today* and in each component.

### Verification before tagging

- Mirrors equal their recorded commits (`scripts/check_components.py`).
- Installer tests, SwarmblyCore documentation-boundary tests and the SwarmblyApp tests touched by this release pass locally; the full matrix runs in CI on push.

- **Documentación del proyecto completo**, en inglés y español: un README rediseñado con un diagrama de flujo animado, figuras de las mediciones publicadas, una simulación del modelo de cobertura y un recorrido por la app; arquitectura, instalación, componentes y mantenimiento, hoja de ruta.
